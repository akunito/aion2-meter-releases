# Settings
- Settings now opens inside the main window (the gear); ⧉ pops it out into its own window. Back, Cancel or Esc discard the changes, Save applies them.
- Language: the interface texts, English or Spanish (Español); the EN/ES chip on the overlay switches too. The help pages have their own EN/ES switch.
- Names: items, skills and monsters: the language of every game name — items, recipes, skills, stigmas, Daevanion nodes, gather nodes, monsters and bosses, in every tab and on the DPS card. "Same as interface" (the default) follows Language; English or Español keeps the names in that language whatever the interface, so you can read the menus in English and the item and skill names as the Spanish client shows them, or the reverse. The "Names" switch in Items and Build and the EN/ES switch in Prices change this same setting. Item and recipe search finds both languages either way.
- Overlay: how the bars are sized, boss HP bar, gear score / combat power after names, show by itself when a fight starts and hide after N seconds, rows shown, background opacity and row size. "Show on all virtual desktops" (on by default): the overlay, its pop-out cards and every meter window follow you to every Windows desktop; untick it to keep them on the desktop they open on. Every meter window (boss timers, breakdown, history, settings, help) stays above the game, but only with the game in borderless windowed mode: exclusive fullscreen covers everything.
- Meter: what counts as a fight (boss only or everything), idle times.
- History: which fights are saved and the minimum length.
- Privacy — the meter has no server of its own and sends nothing about you anywhere. The only setting here is what "Report a problem" puts in its zip by default, which the dialog lets you change each time: logs, crash files, settings (without private addresses) and build info always, plus character summary (names, server, Kina, progress; on), Top DPS rows (player names; on) and inventory (off). Never chat or fight data. The zip stays on your PC: to report a bug, open an issue at https://github.com/akunito/aion2-meter-releases/issues and attach it there (the dialog has a button for that page).
- Capture: the network adapter the game uses; "auto" picks the one carrying the game connection. Without Npcap nothing can be captured: the overlay footer and the tray say "No capture (Npcap missing)", the adapter list and the .pcap recording are greyed out, and this section lists what is off (DPS meter and breakdowns, timers read from the in-game event list, live inventory and character state, your position on the Atlas, packet recording) and what still works (Atlas, Prices, Craft, Top DPS rankings, Build and Daevanion planner, Items from the last saved files, Boss Timers from the shared feed, Abyss Logs lines of saved fights, fight history). "Install Npcap…" brings back the message with the download link that the first start showed. Once Npcap is installed the capture starts by itself within a few seconds, no restart needed.
- Hotkeys: editable, applied after saving.
- Data: skill icons and boss portraits download switch; "After a boss kill, show where your DPS sits among your class this week (Abyss Logs)" (on by default) asks api.abysslogs.com for that boss's weekly statistics. Only the region and the boss code are sent, never your name, class or numbers: the percentile is worked out on your PC. Answers are kept 6 hours.
- Game → Region and Server: the server you play on. "Auto (from login)" (default) takes the character you log in with and shows which one it found; before any login it uses the character you played last, and Vaizel (Europe) when there is none. Pick a server only if you play somewhere else and the meter guesses wrong. Everything that depends on the server follows it after Save: Prices (aion2.exchange prices of that server, polled again at once), Top DPS "Server …" tab and the region tab next to it (Europe, North America East/West, South America, Asia), the Abyss Logs percentile region, profile searches, the account warehouse in Items, the boss timers shown, and the event pills, which run on that region's clock (Europe Berlin time, NA East New York, NA West Los Angeles, South America Sao Paulo, Asia Seoul; the daily and weekly reset is the same moment everywhere). The line under the dropdowns says which server is in use and where it came from. Set it back to Auto when you return to your usual server.
- Game: "Start and stop with AION 2" registers a task for your Windows user (no administrator) that starts the meter when the game runs and closes it a minute after the game ends.
- Updates: the meter checks its own releases shortly after start and every 2 hours, downloads a new version in the background and applies it at the next start or when you are not playing. Channel: Stable (default) or Development builds. Nothing about you is sent.
