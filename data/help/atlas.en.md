# Atlas
A calibrated map of the zone you are in (Verteron, Altgard, Lower Abyss) with your position, gathering nodes, field bosses and pet souls.
## What you see
- Your position: a gold ring. "Follow me" keeps the map centred on you; drag the map to look around and it stops following.
- Nodes: an icon per kind (Kukuru, Odyle, Aria…). Green = in view with the units left, grey = remembered from an earlier visit with the time until it is back, skull = field boss.
- Zones: the kind buttons in the header toggle coloured outlines of the best areas for that material.
- Pets: every spawn of a species whose pet is below level 3. Red = not owned, orange = level 1, yellow = level 2; nothing is drawn for a pet at level 3. Only monsters that really drop that soul are marked, matched by the game's monster id, so mobs that the databases name differently (Crimson Manduri Slinger, Duduka Slinger, Modified Lupyllini…) now show too.
- Objects: every gathering node code and the Empyrean Traces have a name from the game data; you only need to name a node if the atlas shows a wrong one.
## How to use it
- Drag to pan, mouse wheel or the Zoom slider to zoom, "Fit" to see the whole map.
- Right-click a node to name its kind (the same panel opens by itself when you use an object nobody has named). Not a gathering node — a door, a chest, a lever? Type what it was and press "Other (not a node)": it is not drawn on the map and never asked again. "Save as node" keeps a typed name as a node kind missing from the list. Right-click a pet marker for a card with the monster, its level, how many spawns it has, your pet level and the other monsters that drop the soul.
- Zoomed out, nodes of one kind group into one icon with a count; zoom in to see them one by one.
- The "Pets" switch is on by default and your choice is saved.
