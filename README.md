# AION2 DPS Meter — private build (clan releases)

Binaries only. The meter updates itself from these releases: **stable** = the latest release; **pre-releases** = the development channel (Settings → Updates → Channel).

Install: unzip `AION2DpsMeter-vX.Y.Z-win-x64.zip` into a folder of your own (e.g. Documents\AION2DpsMeter), install Npcap once (https://npcap.com), run `AION2DpsMeter.exe`. The guide inside the zip (`LEEME - guia para el clan.txt`) has every step.

Source code is private. Based on cyberbadger6969/aion2-dps-meter (MIT) with private patches.
